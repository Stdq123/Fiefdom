# 《采邑春秋》单位系统设计

## 系统概述

《采邑春秋》的单位系统主要包含：
1. **玩家角色**（主君）：玩家操控的角色
2. **门客**（NPC）：工作单位，共5个学派
3. **访客**（NPC）：随机事件触发者
4. **敌人**（战斗单位）：蛮族、野兽等
5. **动物**（资源单位）：可驯化、狩猎

## 2. 门客系统

### 2.1 门客属性

#### 基础属性

```gdscript
class_name RetainerData extends Resource

@export var retainer_id: int
@export var name: String
@export var age: int                     # 年龄：18-60
@export var gender: Gender               # 性别
@export var school: School               # 学派
@export var loyalty: int                 # 忠诚度：0-100
@export var efficiency: float            # 效率：0.5-1.5
@export var profession: Profession       # 职业

enum Gender {
    MALE,
    FEMALE
}

enum School {
    CONFUCIAN,    # 儒家
    MOHIST,       # 墨家
    LEGALIST,     # 法家
    AGRICULTURALIST, # 农家
    MILITARIST    # 兵家
}

enum Profession {
    FARMER,       # 农夫
    CRAFTSMAN,    # 工匠
    SCHOLAR,      # 学者
    GUARD,        # 守卫
    SERVANT       # 仆人
```

### 2.2 学派特性

#### 儒家 (Confucian)

**特性**：
- 忠诚光环：每个儒家提升其他门客30%忠诚度/天
- 礼仪加成：祭祀活动声望+50%
- 社交能力：宴会成功率+20%

**属性倾向**：
- 效率：0.9-1.2
- 忠诚度初始：50-80
- 适合工作：祭祀、教书、管理

**性格**：
- 喜欢：祭祀、典籍、礼制
- 厌恶：法家政策、奢靡、战争
- 特殊事件：可能被礼制吸引加入

**招募条件**：
- 声望≥100
- "礼"≥Lv.3
- 消耗：100声望或1本典籍

**对话示例**：
- "君子应当遵循周礼。"
- "法家那套实在不敢苟同。"
- "祭祀不可废也。"

#### 墨家 (Mohist)

**特性**：
- 工巧加成：工作效率+20%
- 自动修缮：每天恢复设施耐久10点
- 节俭：粮食消耗-20%

**属性倾向**：
- 效率：1.0-1.5
- 忠诚度初始：40-70
- 适合工作：修缮、制作、建造

**性格**：
- 喜欢：简朴、劳动、科技
- 厌恶：奢侈、浪费、战争
- 特殊事件：发明新工具

**招募条件**：
- 声望≥50
- 拥有工坊
- 消耗：50铜钱或工具

**对话示例**：
- "节俭是美德。"
- "这些工具还能再修。"
- "奢侈之风不可长。"

#### 法家 (Legalist)

**特性**：
- 税收加成：公田声望收益+20%
- 管理能力：门客上限+5
- 严苛：忠诚度<30时可能惩罚

**属性倾向**：
- 效率：1.1-1.4
- 忠诚度初始：30-60
- 适合工作：管理、收税、执法

**性格**：
- 喜欢：秩序、效率、改革
- 厌恶：混乱、传统、仁政
- 特殊事件：推行新政

**招募条件**：
- 声望≥200
- "书"≥Lv.5
- 消耗：200铜钱或竹简

**对话示例**：
- "乱世当用重典。"
- "效率是第一位的。"
- "仁慈是弱者的借口。"

#### 农家 (Agriculturalist)

**特性**：
- 耕作专家：私田产量+50%
- 土地亲和：感知土地肥力
- 耕作建议：提示最佳种植方案

**属性倾向**：
- 效率：1.2-1.5（仅种田）
- 忠诚度初始：50-70
- 适合工作：种田、养殖

**性格**：
- 喜欢：土地、作物、天气
- 厌恶：战争、政治、迁徙
- 特殊事件：发现新作物品种

**招募条件**：
- 声望≥30
- 拥有井田
- 消耗：50粮食或种子

**对话示例**：
- "土地是我们的母亲。"
- "今年适合种黍。"
- "战争只会荒废田地。"

#### 兵家 (Militarist)

**特性**：
- 军事纪律：工作效率+30%（战斗相关工作）
- 主动防御：自动攻击入侵敌人
- 训练能力：提升守卫战斗力

**属性倾向**：
- 效率：1.0-1.3（仅战斗）
- 忠诚度初始：30-60
- 适合工作：守卫、战斗、训练

**性格**：
- 喜欢：战斗、训练、武器
- 厌恶：懦弱、和平主义
- 特殊事件：击退蛮族入侵

**招募条件**：
- 声望≥150
- "射"≥Lv.3
- 消耗：1把武器或100铜钱

**对话示例**：
- "和平是打出来的。"
- "训练不能松懈。"
- "懦夫不配谈尊严。"

### 2.3 门客工作

#### 工作类型

| 工作 | 消耗 | 产出 | 推荐学派 | 效率公式 |
|------|------|------|----------|----------|
| 种田 | 1粮食/天 | 作物 | 农家 | 产量 × 1.5 |
| 修缮 | 0 | 耐久+10 | 墨家 | 耐久 × 1.2 |
| 公田 | 1粮食/天 | 声望+5 | 法家、儒家 | 声望 × 1.2 |
| 守卫 | 2粮食/天 | 安全+5 | 兵家 | 安全 × 1.3 |
| 研习 | 1书籍/天 | 科技点 | 儒家、墨家 | 科技 × 1.0 |

#### 工作分配

**界面操作**：
1. 打开门客管理面板
2. 选择门客
3. 拖拽到工作区域
4. 确认分配

**AI逻辑**：
```gdscript
func _assign_work(retainer: RetainerData) -> void:
    # 优先分配擅长工作
    match retainer.school:
        RetainerData.School.AGRICULTURALIST:
            assign_to_work(retainer, "种田")
        RetainerData.School.MOHIST:
            if needs_repair():
                assign_to_work(retainer, "修缮")
        RetainerData.School.MILITARIST:
            assign_to_work(retainer, "守卫")
```

## 3. 访客系统

当前封地的访客有固定的轮访日和活动地点。季青在南路亭，石墨在水源旁，陶辛在西廊，蒲宁在南边竹径，弋戎在东路岗。封地手记显示当天来客，按 E 和最近的人交谈。当天的来客和交谈奖励可随存档恢复。招募后可在封地再次和同一人物交谈，门客根据职责前往田边、蚕桑棚、堂前或东路。

五位常规来客在晴天酉时沿路去南路亭歇脚，雨天申时提前到亭檐下。邻里手记预告当天的晚间去处，舆图可以跟随正在路上的人。到达后可听到各自的晴雨对白，交谈、交易、招募与委托仍可使用。守备当天以及等候勘渠、溪行手记交接或守备复盘时，来客留在白天的约定地点。读档或从竹涧回来时，按当日时辰恢复所在路段或亭前位置。

晴天酉时起，留任的具名门客处理完手头的田务后会沿南路去亭东席案歇脚。守卫留在东路，来敌时席案收起。席间可以听他们说起各自的日常，仍能接续轮作和邻里委托。新田务出现后，照料和收割门客会回去干活。邻里手记和舆图显示在路上或已经到亭。走到席案南侧可按 E 打开原有「今夜安排」。读档和返程按时辰、天气与待办工作恢复门客位置，过夜回到岗位。

季青在相识和首次纳贡后会请玩家留一份私田作物作路粮。送粮只结算一次，亭旁会出现粮匣。之后再见到季青，无论他是访客还是门客，他都会认得这份路粮。

送粮的次日起，再见季青时可合修亭西歇脚处。木料默认花费 12 铜钱，付清后过一夜，亭西小路会接到长凳和水瓮旁。体力不足时可按 E 歇脚，每天一次，最多恢复 18 点体力。出资日期与当天的休息次数随存档保留。季青留任时可在他当前的岗位接续这件事。

「邻里手记」收录七位具名人物。开局有渠伯，其余人物在第一次打开对话时入册。条目会显示当日来访地或门客岗位，并从各故事进度整理已做过的事和下一步。早期存档中的相识与完结记录也会显示。

具名门客因缺餐或初税亩改革离任后，按原日程回访。重逢时会提起离任缘由，邻里手记保留最近的离任与返岗日期。缺餐离任者愿意在粮仓备齐全员一夜口粮后回来，含自己的一份。邀请沿用招募的声望和每日次数，返岗先做田间照料。议税离任者按通常招募条件邀请。早期存档中已经离任的渠伯也可在回访时备粮邀回，手记从实际返岗日期记起。

开垦簿在田额开放、门客未齐时显示当前可找的来客。陶辛去西市时，可沿指引到绸摊。渠伯在轮访歇日回井田西南时，仍可从簿上找到他。今天无客或已留一人时，按当前留任名单显示下一次预计来访。对话里的招募选项写出声望或口粮缺额。达到中士门槛时，若今日招募会跌回门槛以下，对话显示招募后的声望供玩家决定。

五位常规访客已经相识且当日外出时，手记按当前留任名单、常规轮访和临时来访优先顺序显示下一次轮访的日期与地点。溪行手记齐了，蒲宁每天在南边竹径等候，其他来客照常赴约。轮到蒲宁的日子也可在竹径交接。交接当天他会去药圃看新苗，此后恢复轮访。若已招募蒲宁，可到他的岗位交接。当天读档会按时辰恢复来客去处。石墨完成勘渠、弋戎完成守备复盘后，当天存读档仍保留同一位来客。

共同建成的设施会改变五位常规来客的日常。季青走到亭西照看水瓮，石墨去水源看量水尺，陶辛到西廊整理样绸，蒲宁沿新路查看药苗，弋戎沿东路查看守备牌。来客在途中可停下交谈，结束后接着走。封地手记和人物舆图显示实时去处，邻里手记根据已经建成的设施预告下次来访地。读档或从竹涧返回时，来客会在当天的活动地点。留任门客依照当前岗位活动。

季青修好歇脚处、陶辛收到样绸、石墨完成勘渠、蒲宁交接溪行手记、弋戎立好守备牌后，会随四季和雨天更换返访对白。同一日期与经营状况读档后可听到同一段谈话。季青会回应当天歇脚的经历，石墨会提到实际通水的井田数，蒲宁会说明药圃还需几夜长回新叶。断水、敌袭和尚未完成的委托继续提供当前事情的指引。

第一份公田收成入国库后，渠伯会说起荒年收到的菽种，邀玩家在一格私田试两茬。约定后，在曾收过菽并留肥的私田收下非菽作物，邻里手记记下日期、井田编号和品种。再访渠伯可把收成写进轮作簿，井田西南会接出通往木架的小路。翻簿可标出当前留肥的田格 12 秒。故事沿用田里的轮作产出与结算。渠伯离任后每逢第 3、6、9 天等回井田西南，日常访客照常来访，轮作故事可在回访时接续。已签簿后，渠伯随季节和雨天更换谈话。

谷雨亭集有乐师商音与两位来客。季青和陶辛在亭集上会提到已交付的路粮或样绸。两人有当日约定或已留任时，由林蓼或阿绥赴集。与亭集来客交谈可听到当日的故事。

作物靠渠水长过一夜后，相识的石墨会在有空的日子到水源旁查看。已招募时可去他的岗位。完成勘渠对话后获得放样功能，水源旁立起量水尺。第一次有效供水和完成勘渠的日期随存档保存。

在西廊认识陶辛后，可为他织一匹样绸。交样按售绸结算一次，默认加价 10 铜钱。西廊会挂出一角样布，陶辛的画像和对白会随交付、重访和留任而变化。

交付次日起，蔡娘在西市绸摊陈列样绸，柜台记着织出这匹绸的封地名。陶辛在晴天轮访时先到西廊，巳时沿西路出发，午、未时在绸摊理货，申时返程，酉时走到南路亭。封地手记显示行程，邻里手记和人物舆图可指路。在西市时，舆图按陶辛脚下的位置显示头像，指路标记随他移动。提前到西市可去绸摊等他，返程时封地指向南路亭。选中的指引跨关道和存读档保留，和陶辛交谈后结束。两处交谈、交易和招募共用原有规则。留任后陶辛在封地岗位活动，蔡娘继续陈列。雨天按原来的避雨路线。用样绸交付日期、轮访和时辰恢复行程。

与蒲宁相识后会开启溪行手记。按当日指引到竹涧立牌旁记录木桥、浅滩和望溪台的水迹，每天一处。三处记齐后蒲宁会在竹径等候交接，已招募时可去他的岗位找他。交还手记后，竹径东侧的药圃可在受伤时采收，三夜后再长，灶台东边通往竹涧浅滩的小径也会开放。观察日期、交接和药圃再生进度随存档保存。

击退一场敌袭后，可找弋戎复盘。弋戎会提到谁放了末一箭，以及损失了几格作物。相识后他会在战后返访，也可以在他留任的岗位完成复盘。东路尽头的守备牌可按 E 查看最新战果。复盘后预告会标出来敌，敌袭时守备牌会升起警旗。守备牌、最新战果和当场损失随存档保存。

墨家门客负责缫丝后，可在蚕桑页开启夜间委派。门客吃过晚饭才工作，每人每晚缫一只茧。蚕茧在喂养结算后可用，次日可查看生丝收据。委派开关和上一夜的产出随存档保留。

### 3.1 访客类型

#### 游学士子

**触发条件**：
- 每月随机1-2次
- 声望≥50

**对话选项**：
1. 招募（消耗声望/典籍）
2. 拒绝
3. 辩论（胜则招募，败则失去声望）

**学派分布**：
- 儒家：40%
- 墨家：20%
- 法家：20%
- 农家：10%
- 兵家：10%

#### 商人

**触发条件**：
- 每周随机1次
- 随机天气：晴天

**交易选项**：
1. 购买物品（高于市场价20%）
2. 出售物品（低于市场价20%）
3. 交换（以物易物）

**特色物品**：
- 稀有种子
- 工具
- 典籍
- 装饰品

#### 落魄贵族

**触发条件**：
- 每季度随机1次
- 玩家爵位≥中士

**对话选项**：
1. 招募（消耗丝绸/玉器）
2. 拒绝
3. 捐赠（获得声望）

**特殊效果**：
- 招募后可能带来稀有关系网
- 可能带来特殊任务

#### 蛮族使者

**触发条件**：
- 每半年随机1次
- 北方边境有蛮族活动

**对话选项**：
1. 进贡（和平，消耗资源）
2. 拒绝（可能开战）
3. 辩论（舌战）

**后果**：
- 进贡：和平1年
- 拒绝：50%概率开战
- 辩论胜：获得贡品，和平2年

### 4.1 蛮族单位

#### 蛮族斥候

| 属性 | 值 |
|------|-----|
| 生命值 | 50 |

首次纳贡后，西市绸摊的蔡娘出售一只绵羊。默认 100 铜钱含立栏，回封地可从舆图指路到南路西端。春、夏、秋的晴天在围栏内放牧，傍晚回棚。雨天和冬季在棚边吃草料，每夜取一份。

蔡娘每 6 铜钱备三份草料，在羊棚也可以用一份私仓麦备三份。每天过夜按刚结束一天的季节和天气结算，缺草的一夜暂停羊毛生长。羊棚显示三夜预报，「今夜安排」显示当晚的草料情况。

累计十个饱食夜可以剪下一份羊毛。羊毛可在绸摊按 36 铜钱一份出售，或留两份请蔡娘织成羊毛短衣，在堂屋衣架试穿。饲养、草料、剪毛进度和已做的衣服随本局存档保存。
