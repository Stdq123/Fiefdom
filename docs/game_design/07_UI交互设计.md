# 《采邑春秋》UI交互设计

## 设计原则

1. **信息层级**：重要信息优先显示
2. **操作便捷**：常用功能一键到达
3. **视觉统一**：青铜器风格贯穿全游戏
4. **响应及时**：操作立即反馈
5. **符合史实**：春秋时期审美

---

## 1. HUD设计

左上手记显示当前目标和行动按钮，点「封地手记」展开来客近况。右上常驻日期、时辰、天气、铜钱和粮食。「历书」查看节气与活动，「账目」展开爵位、声望、国库和井田。左下显示气血与体力，右下安排过夜。底部中央常驻七个种槽，可点选或按 1–7。田务按钮显示可收、待浇或断水提醒，点击打开井田页。鼠标指向田格时显示公私归属、操作及耗费；缺水或体力不足会说明原因，湿土和收获提示用于确认结果。

田边提示把操作键与耗力放在同一行。体力不足时仍显示田务名称，并列出差额。成熟作物列出预计纳入国库或带回私仓的份数，适用时也列出铜钱、桑叶和扣税。生长中的作物写明还需供水几夜。田边提示、种槽说明、日期账目、气血和体力随阅读字号放大。铜钱和口粮一行摆不下时各自成行，保留完整数字与对应图标。

田务结果以浮字跟随对应田格，避开 HUD、田边提示和相邻浮字。同一田格连续出现相同提示时，延长原提示的显示时间。受击数字在目标附近分开显示。浮字跟随阅读字号，随镜头移动时保留屏幕大小。打开面板时暂时收起，回到地图后继续显示。

游戏画面直接绘制鼠标指针。地图上的铜镶玉箭头用浅色铜边勾出轮廓，尖端指向实际落点。可用按钮显示带青玉色袖口的手形，灰掉的按钮和正文显示箭头。文字输入框使用铜边工字形光标。切换菜单或弹窗、禁用或恢复按钮时，鼠标停在原处也会换成当前界面的指针。拖动门客时，箭头旁的青玉印带勾表示可落位，朱色印带叉表示不可落位。门客姓名随指针显示在右侧。切换到手柄时显示准星，移回鼠标后恢复对应指针。窗口边框使用系统指针。

五种指针均为本项目原创绘制的 32×32 透明 PNG。拖放指针与普通箭头共用 `(2, 2)` 热点。

指向体力足够且可操作的田格时，箭头旁显示小锄、种粒、水滴或镰刀。整田操作按预览的总耗力判断，整备时先显示当次作业的第一件工具。体力不足、作物无需照料或离开田格时收起图标。贴近画面边缘时，图标换到内侧，箭尖仍指向实际落点。

指向需要耗力的田务时，体力条用斜纹标出同一笔预计耗力。剩余体力不足时用叉记和「不足」提示，归零时显示「已尽」。移开准星或打开面板时收起预览。封地和竹涧共用气血、体力条。扣减时读数立即更新，原先的余量留下短暂的暗铜色痕迹。恢复时亮出刚恢复的一段。警告出现和收起时两条读数的位置保持一致。

走进互动范围后，当前人物或器物的提示贴在目标附近，避开主角、常驻 HUD 和窗边。换镜头倍率时按屏幕字号显示，文字随阅读字号调整。提示沿用当前键位和目标状态，例如书案是否还能研读、织机用料和钓点条件。打开管理、舆图、设置或对话时收起提示，关闭后根据当前目标恢复。

写好续播安排后，种子栏会显示「按安排播种」，手柄可用 LB/RB 切到这一档。单点可播的空畦按该格安排下种。按住批量键或 LT 时，各可播田格上预览作物图案，提示列出公私田格数、品种和总耗体力。选任一种子可回到手选模式。

种子栏的田务按钮可直达井田舆图。「待播」用绿点标出已翻、有安排、现在可下种的空畦，各井田旁列出数量。点「待播」会选中「按安排播种」，从近处开始标记，先指完同井田的剩余空畦再换一块田。当天存档继续时按剩余田格恢复，播完、过夜或换回手选种子时收起指路。

井田列表另列出可按计划开种的「待翻」格数。选中「按安排播种」后，种子栏可开启「整备空田」。按住 Shift 或 LT 指向可播的计划田，预览本井田的品种、翻地、播种、浇水格数和总耗体力。左键或 A 确认。松开批量键时可单格操作。选回某种种子会退出整备，续档时可从种子栏重新开启。

谷雨亭集与夏至试筏从前一日开始在日期栏显示提醒。秋社和冬至围炉按备办作物的生长夜数提前提示，默认三天。点活动条或按历书快捷键可翻到活动当天，点「历书」可查看今日。秋社列出私仓谷样、已熟私田和当日仍能赶上的旱作。冬至比较两道菜需要的食材与份数，同年秋社留样后记入禾伯所出的菽。缺鱼时可从围炉页标出已开放的南池钓台，或在学过垂钓后前往柳湾。翻阅历书时暂停时辰，选择指路后回到地图。

「今夜安排」在标题旁显示明日节气与天气，点击直达明日历书，可查预计轮访和敌情。历书可翻到往年查节庆记录，或翻到下一年查日期，再用「回到今日」返回。选中本季或下季时可打开对应的交货簿，随后按现有方式备货与跟踪。

小雪和大雪时，日期栏与历书写「落雪」，时辰牌与晨间简报显示雪花图标。历书和水迹记载按所选日期显示天气，明日预报按次日显示。谷雨的旱作得水说明沿用原样。

历书在节气旁标出「今日」「明日」「几天后」或「已过」。正文跟随阅读字号，可在右页滚动，日期、节庆指路和留料按钮留在页内固定位置。方向键和手柄十字键可在季节、日期和可用操作间移动。在滚动条上按上下翻读长记事，按左右回到日期或移动到可用操作。Tab 和 Shift+Tab 在历书内循环。

活动详情底部可点「夜里留谷样」「留麦菽粥料」或「留鱼麦羹用麦」。选择后详情显示私仓中额外留下了什么，哪些还在时令单里。还没收获时可先设好，收获后会计入留用。

备办期间的钓鱼结果显示冬至日期，可点「去南池畔围炉」。指引跨地图接续，也可在存档后恢复。现场缺鱼时，禾伯的菜单同样可以标出钓点。

每格收割都有镰刀动作、断穗和音效。接连点收、拖收或门客代收时，种子栏上方的收获回执合计入库、作物和实际入账的铜钱，有桑叶或税金时一并列出。单格收成保留作物名和代收人，轮作增收及留肥在同一张回执里提示。

地图中心上方用漆木底板显示首份纳贡、返程田务和出行提示。文字随阅读字号调整，长回执在日期和手记之间换行，晨间简报出现时回执排在下方。打开舆图、设置或其他面板时，地图提示收起并暂停计时。回到地图后，提示接着显示剩余时间。互动提示避让可见的回执，回执淡出后释放这块空间。

手记由竹片编成，上下各有一道束绳。工具和过夜按钮是系绳木牌，过夜牌涂朱漆。历书和外出地名用暗铜底与浅色文字，封地以十二刻的铜盘显示时辰，右侧另列天气。种子装在漆木槽里，选中的种槽用朱漆底与亮边标出。背包打开后是一只黑底朱绘的漆木匣，分类标在竹签上，物品、数量和空槽都在分格里。布币图标旁保留「铜钱」文字。

将鼠标或手柄光标停在种子上可查看作物卡。成熟贴图下衬该作物的古字，旁边列出繁体字头、可查证的字形年代、种植用途和今日播种所需夜数。

「睡觉」「今夜安排」及设置等按钮的悬停说明使用暗铜底板和浅色文字，文字跟随阅读字号调整。较长的说明在板内换行，光标靠近窗边时，说明留在游戏画面内。

新建封地时，进场短提示交代渠伯留下了交接简。首次纳贡前，可从手记读简，查看中央公田和四周私田的用途、首贡所需的一份作物和期限。简上默认选中「标出公田」，选定后回到封地，标出公田及当前操作。想先请教时可选「去见渠伯」。九格图用文字标出公私归属，书信、说明、期限和指路文字随阅读字号调整。读取旧进度时，可继续读简，交接提示只随新建封地出现。

第一次纳贡前，手记根据田格的当前情况提示翻地、播种、浇水或收割。「标出公田」可直接跟随手记所指的田格。种子需要换成黍时，按钮会写明先选种再标田。公田超出视野或被界面挡住时，屏幕边缘会指向它。首贡份数和期限各阶段都显示在田务提示下方，今夜到期时有明确文字，点击期限可查看今夜安排。手记标题、正文、期限和行动按钮随阅读字号调整。公田有水、还在生长时，可以从手记给当日来客或渠伯指路。第一天和渠伯交谈时，他会说明公田纳贡、私田换粮的用途。首次公田收成入库后，地图标出手记所说的私田，玩家可自行点「找渠伯谈轮作」切换指路。邻里手记的「在地图上找」也能指向人物现在的位置，交谈或人物离场后清除标记，可从封地手记取消。

首次纳贡前，公田有水时可以从手记选「兼种一格私田」。手记标出一格可耕作的私田，也可切回纳贡指引。两块田一起播种和浇水时，可以在同一早晨看到公田入国库、私田入私仓并赚铜钱。过夜后先处理缺水的公田，公田浇好后优先指向较早可收的私田。

对话在底部展开双编绳竹简，青铜小座托住肖像，姓名旁的朱漆签标出身份或地点，回应也用朱漆签。长对白会撑开卡片，选项空间不足时可换行。只有一个可用选项时，按当前互动键或手柄 X 继续。多个选项时，方向键或手柄十字键在可用选项间切换，回车或 A 确认。打开时焦点落在结束对话的选项上，Esc 或 B 可直接返回。

正文超出卡片时，底部显示页码和「上一页」「下一页」，肖像与回应留在原位。卡片内可用滚轮卷读，PgUp、PgDn 和手柄 LB、RB 每次翻近一屏，保留上次读到的一行。Tab 可在回应和可用的翻页按钮之间移动。翻页键改作互动键后，提示按新键位更新，仍可用按钮翻页。连续对白保持在对话中，最后一张关闭后，焦点回到打开对话前的可用控件。

田格的悬停提示和田务指路共用封地界面的遮挡范围。田格提示优先贴着田边，避开手记、历书、种子栏和收获回执。田边位置被占用时，提示移到最近的空位，露出当前田格和正在这格干活的门客。井田指路仍标出下一格可收、待浇或断水的作物。

一块井田内有多格可做同一件农事时，田格提示会写明可按住 Shift 或手柄 LT 预览。预览描亮受影响的格子，准星所在格用亮角标出，公田格内另有金角。字旁的锄、水滴或作物图标对应这次田务。提示分别列出公私田数量和总耗力。体力不足时显示差额，松开后回到单格提示。

公私田都有成熟作物时，井田舆图在「可收」旁列「收公田」和「收私田」。选中后，批量收割限于指路的田类，做完当前井田后接到下一块。筹备账的「指路收公田」使用同样的范围。预览列出实际入库、入仓、铜钱和实扣税，再确认收割。松开 Shift 或手柄 LT 可对单格收割。取消指路或选「可收」可用整田批收。同日续档恢复分收范围，过夜后重新选择。

在田边水源按互动键或手柄 X，可查看渠水用途和书艺门槛。书艺未到 3 级时可直接打开六艺研读，达标后可进入科技解锁水利。解锁后可查看接水的井田数和田格数。当第一块井田还无渠水且有可直达的渠线时，会列出尚需开挖的格数、铜钱和缺额。选「标出引水位置」进入挖渠，沿金框逐格施工。接通后金框消失。

本季或下季夏单的备稻量超过私仓、已熟稻和接水私田可提供的数量时，交货簿可跟踪该单并指路去水源。西市先指向东口，经溪桥道回封地后接到泉边。路线与订单进度都可随存档恢复。已有水利时，泉边按现有渠线为首块井田报价，优先给所缺的稻留出足够私田。选「标出备稻渠线」后金框标渠，青框标田。玩家逐格开挖，退出挖渠时自动选中稻种。

顶部「舆图」和 M 打开封地舆图并暂停活动。地点、井田、人物和竹涧四页可选指引目标，M 或 Esc 回到封地。工地完工和人物到访状态在下一次打开时更新。「竹涧」显示当日可采或可钓的东西和东岸风险，选定地点后指引从封地东关接到竹涧山路。

井田页按田区取景，露出井田周围的道路和田口。田区太宽时，先看编号、工地和各田的任务数量，点一块井田即可放大看田格并标出目标。田格区分已翻土和渠水，公田有金框，改为私田后随账目更新。缺水、待播和已熟符号按田格落位。人在图框外时，金色箭头指向当前位置；点地点页可查看整个封地。

舆图地点页和六艺页均可指路到驾御场。在屋内选中时提示从南门回封地，地上的金线沿东关前的岔路到坡下马车。上车后底部种子栏换成驾御进度和下车按钮。开始移动后倒计时启动，当前旗门和停车线依次亮起。完成后显示用时和所得御经验，六艺页保留最快用时。

首次纳贡后，可以循标记找渠伯谈轮作。尚未收过私田时，手记会标出私田，优先指向已种、较早可收的作物。答应轮作后，翻好空田会标出菽种。首年任下士时，私田收成入仓后可从手记查看今夜粮耗、时令交货期限、备货进度和报酬。转粮按钮写明取用哪种作物，交货会用到的作物也会标明。可换一份口粮，或留作物并打开时令单。作出选择后收起这条指引，存档保留选择状态。

封地管理与西市收货牌共用交货簿。本季和下季都用同宽货签标出货物图样、备货进度和缺的份数、尾数或匹数。有库存需先留给本季时，下季货签写明仓内有多少、先给本季留多少，再显示下季还差多少。已交后写明交付数量。截止日留在页首，余下两天或一天时高亮。用页首的「本季」「下季」翻读，西市交货簿用同一个滚动区。货签、托付、备货指引、报酬和回执随阅读字号放大。切到下季备货按钮时，正文随焦点移动。

打开本季交货簿后，可直接标出需要收获或浇水的私田。来得及补播且有可用田格时，可标出空私田并换好种子。按标记翻地和播种，浇完后显示预计收获日。过夜和续档后会重算这张单还缺哪种作物、下一格需要做什么。已有田苗够用时提示照料或等待。新播赶不上截止日、稻田无渠水或已有其他续播安排时，只提示可行的田务。备货齐全时，封地交货簿页首和田边跟踪条都可指路去西市收货牌。

有管事和可用私田时，本季交货簿或下季预告会显示「安排管事备货」及准备播种的品种、格数和预计收获日。确认后可在封地概览看到「备货」田格，也可回单据「撤回未播」。管事已安排的格数计入备货指引。若调走管事，交货簿提示需要重新交接的格数。下季单的跟踪会给备粮保留货物，货齐后从田边按指引去西市交货。

从封地交货簿的下季预告也可标出私田并换好所需种子。预告分别写明作物最早可收日和订单开收日。跟踪后，田边条目随播种、供水和成熟更新。若开收前已经备齐，条目显示开收日期。进入下一季后再点即可指路交货。

公田收成首次入库后，堂前石坪添一袋谷和一枚竹筹。走近可翻看「贡粮账」，读到首份收成的日期、井田、作物、份数和经手人，以及累计纳贡、下期份数和期限。有后续田务时可从账中标出公田。旧档已有贡粮时仍可查累计和期限，首笔明细随实际登记保存。渠伯当天邀谈轮作时会说起刚入库的作物。

封地手记在首贡入库前持续显示所需的一份公田作物和期限。过夜提醒并列写出期限与逐夜供水下的最早收成日，赶不上时直接提示。断水稻田先提示接渠，已熟公田可指路收割。提醒优先选中与当前田务对应的指路选项，也可按「仍然过夜」确认。

首次纳贡后可点下次期限打开「今夜安排」。纳贡栏写明本期所需的一份公田作物、期限、欠贡的声望损失和最早可收的公田。累计纳贡显示为长期奖励。「找可收田」和「找待浇田」可以直接在地图标出相应的田格。空地可选短周期旱作并标出播种格，已播种时可循标记浇水、接渠或收割。成熟日期按后续每夜供水估计。公田入库后期限重新计算，发生的扣分可在「昨夜结算」重看。

敌袭前点手记里的预告可查看备战办法、当前的射箭操作，以及屋外试射的提示。击退来敌后，手记的「守备战报」可重读战果。弋戎在外时标出他下一次来东路岗的日期，在封地时可直接指路找到他。复盘后东岗守备牌接手记录。

收过私田后，封地手记显示中士的声望门槛和招募花费。有照料门客时，「首茬收成」可选「安排门客种下茬」，直接打开第一块井田的选种。首茬去处选定后，可从手记去见尚未交谈的来客，也能循标记继续照料公田。公田成熟或当夜有欠贡扣分时，手记优先提示可做的公田田务。达到晋升条件可打开「今夜安排」，过夜核定后显示新爵位和井田上限。

首贡和私田同批收完时，手记保留「轮作试种」入口，可先找渠伯约定，再标出一格私田。确认标记时可换菽种或黍种。田格状态显示待浇、可收、断水等下一步。指路跨夜并随存档保存，收下菽后可再打开手记，标出留肥的私田。已有能用于试种的留肥田时可直接跟进第二茬。收下增产的作物后可指路记簿。渠伯离任时显示回访日期，记簿后可继续从手记找轮作簿，直到这块井田交给管事。

晋升中士后，手记显示下一爵位的声望与六艺要求，可直达六艺研读。玩家也可从手记查看开垦筹备。材料齐备或第二块井田在建时，手记会提示可开垦或正在施工的夜数。「开垦井田」账页分开列出立桩铜钱、立桩用粮，以及扣除立桩用粮后可供施工的口粮。每笔账写明所差数量。施工口粮按现有门客预估，立桩仍按田额、门客人数和一次性费用判定。备粮入口会带回原先选中的田址。

账页随阅读字号调整。地图和账页的九格图用加号标明接得到渠水的田格，用叉号标明受阻的田址，文字说明压到路肩、水源或其他边界的原因。账目可滚动，田址、备粮、立桩和返回留在画面中。开垦第二块井田前，新招门客且预计今夜无法供齐口粮时，手记可直达备粮。

打开开垦账页时选中「返回」。Tab、方向键和手柄十字键在账页内移动选中项，手柄仍可用摇杆指向田址。焦点所在的备粮入口随缺额清除时，焦点回到页脚。按 Esc、手柄 B 或点「返回」，回到打开账页的按钮。

晨间核定晋升后，堂前台阶左侧挂出「爵册」。木架露出顶面和近侧，依脚点排序，挡住玩家时淡出架身。走近可读最近一次升降爵的日期、新爵位、井田上限和已开田数，再从爵册打开开垦面板。削爵后换上现爵的封皮并更新田额。旧档已有爵位时可查看现爵和田额，若最近一次晨间结算含升降爵，爵册补记该日。

管理面板的市场显示粮仓、私田库存、铜钱和当前门客每夜的粮耗。三种交易共用数量框，点击前显示该笔收支。报价旁列出出售或转粮缺的作物和买粮还差的铜钱。「三夜口粮」和「开垦备粮」显示要转的余粮、要买的份数和费用、为订单和节庆留下的作物，以及需留的研究费。缺粮多于余量时，可以勾选「动用预留作物」，在报价里核对会用掉的留货。每次打开面板或切换备粮用途时从保留留货的报价开始。库存或用粮变动时以新报价为准，确认后整笔入仓。

管理市场的「指路去粮摊」先指向西路，进西市后继续指到粮摊。M 或手柄 Y 打开西市舆图并暂停活动，可点选摊位、收货牌和回封地的关口。粮摊复用市场交易表，并写明购入当季特供所差的铜钱。鱼摊的普通换粮、出售和留鱼单都标出每次交一尾。绸摊列出每匹售价以及售后余绸和钱袋余额。靠近摊前按 E，按 Esc 回街上，交易和设置面板打开时时辰暂停。正文铺满柜台的可读宽度，报价随阅读字号调整。滚动时标题和离开按钮留在页首，Tab 在当前柜台内循环。

粮摊、鱼摊、绸摊和羊毛柜台在页首显示当前钱袋与粮仓余额，最近一笔成交的回执留在报价上方。回执沿用背包或鱼篓的货品图样，列出本次交付的作物、鱼、丝绸或羊毛，以及实际收支。粮食到账注明入仓位置。长回执随阅读字号换行，翻阅报价时仍可查看。柜台打开时收起街头的背包按钮。离开柜台或切换摊位时收起本次回执，留鱼单的交付日期和历史结果仍在原条目可读。

已交的时令单显示发车和预计到货时辰。「指路去卸货场」经西市东口、溪桥道回封地，再沿南路到停车处。指路随存档恢复，抵达后显示到货时辰或申禾的互动键，问过申禾后清除。靠近候货座可查预计到货时辰，同日尚未到货时可选「坐等到货」。坐下后看进度，也可点击起身、按 Esc 或手柄 B 返回。换季当日，新一季尚未交货时，交货簿会显示上一季货车的到货时辰或已到提示，仍可循指路去卸货场等候。

走近摊前会看到摊主姓名。打开柜台后，肖像与摊主的话放在交易账的左侧。渔生会说明去哪里学钓鱼、怎样交留鱼单，以及本季留鱼是否已经收到。绸摊切换到羊毛交易时继续由蔡娘接待。

时令单缺鱼时会显示当天的钓点或鱼的栖息提示。学会垂钓后，可从封地或西市的时令单、西市鱼摊给当天能钓到的鱼种指路。西市出发先标东口，经封地东关进入竹涧后接到钓点。体力不足或当天的垂钓机会已用完时，交货簿会显示原因。

封地溪鱼簿在页首分别列出柳湾、砾滩和南池钓台的鱼情与开放条件。可以给当天可钓的地点指路。南池按夏单到货开放，竹涧须先找蒲宁。体力不足或当日起过鱼时仍可查鱼情，已下竹笼另列预计可收日和指路。

溪鱼簿和西市鱼摊共用鱼签。鱼篓为空时，已记的鱼仍保留首获日期、节气和地点。留粮或出售可能导致备货不足时，鱼签会提示涉及哪张单。两张单各需一尾且鱼篓恰有两尾时，也会提示换掉一尾后的余量。鱼签、报酬与留鱼单随阅读字号放大，鱼摊的离开按钮与粮仓余额留在页首。

钓鱼结果和竹涧舆图可为当前能交的留鱼单或带鱼的时令单指路。两单均备齐时，鱼摊和收货牌分别可选。返程沿竹涧西门到封地，再走西关至所选去处。取消指路会清除整段目的地，在三张地图上存档都可接着走。

竹涧右上角的「设置」、Esc 或手柄 B 可在山路上打开系统设置并暂停活动。「保存游戏」记录当前站位和面向。标题与存档列表显示「竹涧」，从设置内读档默认先看当前封地的记录。缺少可用站位时，从记录中的西门或南路小径内继续。

「睡觉」上方的「今夜安排」显示缺水或口粮信息。打开后可以看已有多少作物可收、明早公私田各有几格新熟，以及停长的原因。「找待浇田」优先指向公田，同类田格中选离玩家最近的一格，供水后清除标记。

今夜账册顶部固定显示纳贡期限、田务和口粮摘要。页首、摘要、明细、操作以及购粮上限的金额和分餐菜单随阅读字号调整。较长的摘要换行，滚动正文时仍可看到摘要和过夜按钮。选摘要可跳到对应条目，焦点落在可用的指路、备粮或田务操作上。用手柄时，从口粮摘要按右可去滚动条，按上下翻读，按左回摘要。「昨夜结算」页从右上关闭按钮按下可读长账，返回今夜页后恢复摘要。

有照料、收割门客或管事能接手田务时，田务栏会列出涉及的田格数，可点「等门客收工」。同一张账接着显示实际浇水、收割、补播、入库、入仓和耗时，重算今夜生长和备粮。当天剩余时辰不足时，提示可亲手处理，旁边的指路仍可用。用键盘或手柄等待结束后，焦点移到「过夜」。

首次纳贡后，田务栏提供「过夜前让门客收工」。勾选后，按剩余时辰和实际收工顺序预估作业、明早新熟及仍待浇的田。公田预计浇好或入库时，纳贡栏也会提示。当前可收、待浇的田仍有各自的指路入口。开关随存档保留，鼠标悬停「睡觉」时可以查到。若做完田务仍预计有人缺餐离任，过夜提醒说明已收工，并优先给出「查看今夜安排」。清早从「昨夜结算」可查睡前收工的格数、收成去向和耗时。

首次纳贡前，手记写明播种后还需几夜供水。公田待浇、断水或已熟时，点「睡觉」或从「今夜安排」过夜可看到提醒。首贡期限与可预估的最早收成日并列显示。公田指路选项默认获得焦点，人在堂屋时也会提示从南门回田边。「仍然过夜」照常结算。首贡期限当天，即使尚未播种，提醒也先列出按当前分餐可得的讲学声望、欠贡罚额和扣后声望。达到削爵线时写明将降至哪个爵位，下士则提示将失去封地。「今夜安排」与爵位页沿用同一预报。

蚕桑页顶部用背包图标显示桑叶、蚕茧、生丝和丝绸。建蚕室前可对照书等级和铜钱。建成后，养蚕、缫丝和织绸各有棚内器具图、配方和缺料提示。养蚕同时写明首夜和整批用叶。单件缫丝、织绸与可用的批量操作并排，出售、进献和去蚕棚的指路入口留在下沿。

正文和操作文字随阅读字号调整。用 Tab 移到夜间选项时正文跟随滚动，可以聚焦滚动条读到底。两项夜间安排分别控制续养和门客缫丝。蚕桑页和「今夜安排」共用喂叶、结茧与缫丝预报，过夜后可重读实际结果。蚕棚左侧沿用蚕桑页的四种材料图和数量，分行显示这批蚕的喂养状态与昨夜实绩。正在养蚕时写明今夜还缺几片桑叶，空匾自动续养按整批用叶显示缺额。字号放大后整张材料卡可换行，南门仍完整可见。接近一个工位时，操作键下方显示当前用料或缺料原因，并避开库存栏。

同一面板可设置夜间备粮、购粮上限和缺粮时按整份补粮，预览用粮、留货与费用。换季时按次日时令单留货。次日应缴的研究费显示预留金额或备粮后的缺额。缺粮时可选择先供哪位门客，预览足份、缺餐和离任名单，也可打开市场备粮或调整门客分工。

设置过节庆留用时，「今夜安排」在用粮预报下方列出节庆和时令单各留了哪些作物。点「取消节庆留用」立即重算转粮与购粮费用，并把焦点放到夜间备粮开关。

预计有人因缺餐离任时，点「睡觉」或从账上点「过夜」会列出姓名和当晚能分出的份数。「查看今夜安排」会打开分餐预报，并选中可用的备粮入口。玩家也可确认「仍然过夜」，或按 Esc 或手柄 B 取消。首贡到期时，讲学门客缺餐也可从同一张提醒打开分餐预报，公田指路仍是首选。

提高购粮上限也无法供齐时，可从今夜安排查看蚕桑。有可用丝绸且一匹的售价能增加报价中的补粮量时，面板列出卖绸后的库存和可补口粮。报价预留议税或传统路线还需要的匹数、本季未交订单和已跟踪的下季订单。出售一匹先收铜钱，玩家再决定是否启用夜间备粮或调整上限。实际购粮仍随过夜结算。

转粮、购粮和一匹余绸仍无法供齐，且今日尚可采集时，「今夜安排」会标出野果的入仓量并提供指路。由东关进入竹涧后接续至野果坳。采摘与望溪台的野药共用当天的一次采集机会。

回封地后短暂显示这趟外出期间新增的田务和收成去向。同日再次回封地时，已经报过的田务仍可在「今夜安排」查到全天累计。

卯时揭幕后，工具栏下的暗铜简报显示新一天、节气和天气。发生来敌、研究费缺额、欠贡或缺粮时优先提示。其他早晨可显示升降爵、井田完工、实缴经费或公私田各自的新熟格数。文字随阅读字号增大。揭幕结束即可操作，简报停留数秒后淡出，打开账页或舆图时让出画面。

晨间简报会把来敌排在最前，另列昨夜未缴的研究费、欠贡扣罚、缺粮和离任。日历下的「昨夜结算」显示昨夜提醒的总数。打开后，欠费、欠贡、缺粮和公私田新熟数固定在账页上方，翻阅田务、用粮和蚕棚实绩时仍可看到。昨夜买过粮或转用作物后仍有缺口，照样写明还缺几份。

前一天的外出田务注明日期，在睡前收工记录旁可重读。昨夜结算页首保留当前可用的入口。来敌尚在时可标出位置，欠贡后可标出公田，口粮仍有缺额时可直达今晚分餐。已经成熟的田和昨夜完工的井田可直接指路或安排。收下当前熟田后，指引接到下一格。历史记录随晨间档和手动档保存，旧档已有的田务和用粮记录也可在同一处查看。

邻里手记的名单只列已相识的人，头像旁显示来访、留任、西市行程或下一次轮访日期。人物页首保留头像、相识日期、当前去处和指路。约定和记事在下面滚动，姓名和各段正文随阅读字号放大。用键盘移到名单底部时，名单随焦点滚动。

邻里手记在人物原有故事下记离任与返岗。回访时可在手记指路，交谈后选「请回来」。缺餐离任的对话和手记列出粮仓现有口粮、返岗后的总粮耗和缺额。粮仓备足且满足招募条件时，「请回来」可以确认。

两位邻居实际同席并有新话时，「今夜安排」会列出题目、在席人和地点。「指路去席案」回到封地地面，晴天指向亭东席案，雨天指向雨棚。外侧的「今夜安排」按钮也会报「灯下小谈」，缺粮和纳贡到期优先显示，悬停仍可看同席提示。席案和舆图可查当时的小谈。选择听小谈后，主角在席案前坐下，两位邻居面向彼此。对白换人时，竹简上的肖像和席间的小气泡一起换到说话的人。也可直接打开「今夜安排」。每句话沿用单选对话的 E、回车或手柄确认。中途离席时主角站起，两位邻居转回桌边。听到最后再起身，邻里手记显示日期和谈话内容。同一天重读存档会保留已经听完的记录。

两位相关邻居今晚都能赴席且小谈还没听过时，「今夜安排」和这两位的人物页会提前列出题目、人物、时辰和地点。点「指路去候席」可走到当天的席案。到后选择「坐下候席」，时辰加快到晴天酉时或雨天申时，接着等人物沿实际道路走到席上。到齐后恢复操作，手记改为「指路去席案」，到席边可按交谈键听小谈。途中可按起身按钮、Esc 或手柄 B，保留已经走过的时辰。候席在同一天进行，守卫留岗，来敌时停止。

六艺页在六张牌面上列出各门的等级、本级经验和经验来源。研读旁显示离书艺下一级所差的经验，本次研读足够时会提示。每天可免费研读一次，次数随存档保留，过夜后恢复。

书达到 2 级可到蚕桑页建蚕室，牌面旁列出建造所需铜钱和缺额。书达到 3 级可从科技页解锁水利，两处都有直达入口。中士可查晋上士所需的最高一艺，大夫可查晋卿所需的六艺达标项数。正文随阅读字号放大，练习和返回入口留在画面内。

科技页分列水利、复合弓和爵位。水利牌写明书艺门槛和挖一格渠的费用。解锁前可查看研读，解锁后可查接水井田、钱袋和缺额，也能从同一位置指路去泉眼。复合弓牌列出射艺门槛和解锁后的效果，未达标时可查看六艺牌上的射艺进度。

爵位牌列出下一级需要的声望和晋升后的井田上限。下士可核对周礼，中士可看最高一艺，大夫可看六艺达标项数。已有欠贡时提示下次结算日期。今夜到期时按当前声望估算扣后的余量，并在会影响晋升时提示先补纳贡。科技页的正文和操作随阅读字号放大，选中栏目后可按下方向键进入水利牌。

## 2. 主要面板

### 2.1 背包面板

在封地、竹涧、溪桥道和西市点击「背包」，也可用默认快捷键 I。打开时暂停场景，Esc、手柄 B 或再次按背包键关闭。键盘和手柄都可操作分页与关闭按钮。

「私仓作物」「鱼篓」「工艺材料」各有固定格位。私仓沿种子栏的顺序排作物，用斜俯视的穗、荚、果实和麻束图样表示收成，旧档中的混存作物放在末格。物品名称和图标靠左，数量在格内右下方对齐。库存增减时，原位在物品格和空槽之间切换。侧栏列出铜钱和随身路餐，可在这里吃掉路餐以恢复体力或气血。谷物转粮、交货、售鱼与制作保留各自的业务入口。

每页初次打开时查看第一个有货的物品。点击物品或用方向键、手柄十字键换格，格板下显示放大的物品图样、用途和相关的本季交货数量。已备足或尚缺几份会标在该物品下方。用 LB、RB 翻页后会看到该页上次选中的物品，向下可回到那一格。空槽跳过焦点，所选库存耗尽时详情转到第一个仍有货的物品，格内焦点回到竹签。数量、物品详情及路餐和野药说明随阅读字号调整。

### 2.2 门客管理面板

Windows 版从顶部直接选择封地概览、市场、君子六艺、科技、蚕桑、溪行手记、时令单、邻里手记和溪鱼簿。栏目一行显示，当前页有金色选中状态。键盘用左右方向键选栏目，回车打开，向下进入当前页。Tab 和 Shift+Tab 在当前面板内循环，方向键也留在面板内。Esc 返回。手柄 LB/RB 可循环换页，平时在封地用 LB/RB 换种。

门客名单在左侧，可分派职责，或把人物拖到封地概览的井田格指定优先田。溪行手记、时令单、邻里手记和溪鱼簿用整页宽度显示。打开管理面板时聚焦当前栏目。下拉菜单和「今夜安排」各自接收导航，肩键会保留下面的栏目。下拉菜单可用十字键上下浏览，自动跳过不可用条目。按 A 确认高亮项，按 B 返回原控件。也可用摇杆和 A 点选，将光标移到列表外再按 A 会合上列表。「今夜安排」打开后，手柄光标落在默认选中的按钮上，按 B 回到打开它的按钮。

封地概览的井田选择旁列出公田、私田和接到渠水的格数。九格图使用田里的畦面和作物阶段，可收用实方，待浇用空菱，断水用叉号，文字也标明当前田况和下茬安排。概览、田格和下拉菜单随阅读字号放大。管事与续播说明可滚动，选田、选种、批量安排按钮和九格田留在页面里。

溪行手记用木桥、浅滩和望溪台的图样区分三页水迹。每页记下记录当天的日期、节气和雨晴。今天的水迹地点与下一步留在页首。可从这里标出东关，入涧后在竹涧舆图选「今日水迹」找立牌。蒲宁来访或等交接时可直接标出他的位置。交接后可标出药圃，并查草药的恢复量与长出新叶还需几夜。

手记旁列出野果坳和望溪台的采集收获。野果和野药每天共用一次采集机会，水迹另记。手记正文、采集说明和指路按钮随阅读字号放大。

门客名册显示今夜实际可供的份数，可在同处打开「今夜安排」调整备粮。每张卡片显示当前职责和每夜用粮，有缺餐或离任预报时标在对应门客名下。展开职责菜单时，每个可选岗位列出个人需用的份数。预计缺餐时写出整桌可供与所需的份数及可能离任的人名。备粮能供齐且需要购粮时，列出铜钱开支。「交给管事」的预览也使用同一份分餐账。选中岗位即改派，取消菜单后可继续原来的工作安排。

与渠伯记完轮作簿或第二块井田完工后，职责菜单可选「井田管事」。管事卡片上可选择一块完工井田，拖到田格也会切换负责的井田。封地概览显示该田的管事，续播仍在田格或批量安排中设置。卡片、口粮摘要和职责菜单随阅读字号调整。门客多时可滚动，键盘焦点移到下一张卡片时，名册会跟随滚动。

轮作簿的「安排轮作与管事」打开簿上记录的井田。「昨夜结算」可打开刚完工的井田，舆图也可打开所选的完工井田。封地概览在交接前比较全员每夜粮耗与粮仓现量。勾选「补齐续播」时列出要补的公私田安排，玩家可取消勾选。新田还有生地时可勾选「包括未翻地」，确认前会给出需由管事先翻的格数。

### 2.4 事件面板

晋升中士后，封地手记可打开议税筹备账。日期和爵位单列，公田占比旁写明累计纳贡、私田收成和缺额。成熟田地的收成预估列出两种收获顺序。日期、账目和筹备说明随阅读字号放大。正文可滚动，查看井田、六艺和续播等操作留在页尾。六艺条件未满足时可打开六艺页。公田指路会接续到下一格成熟公田，并随手动存档保留。

上士可在筹备账的「收割安排」选择「北排三格纳贡」。九宫图以金框标出纳贡格，下方列出国库和私仓的熟田收成预估。井田舆图的图例也以金框标明纳贡去向。召简来访前可点「北排恢复私收」。若已暂留其他熟私田，可在同一栏恢复门客代收。

纳贡仍有缺额而公田未熟时，筹备账列出可照料的公田、需做的田务和最早可收日期。空田可选种并标出。有别的公田可生长时会优先推荐，只有断水的稻田时会提示接渠。点「查看井田」仍可打开井田舆图。

已有收割或照料门客时，筹备账可选「暂留熟私田」。门客照常收公田、浇水和播种，外出和睡前候工时也把熟私田留给玩家。玩家仍可亲手收获。安排随存档保留，延期研究时也继续生效，可在「今夜安排」恢复代收。传统或改革定案后自动恢复。

纳贡还有缺额且私田有续播安排时，筹备账列出仍在续播的格数，可直达此类田格最多的井田。续播页预选「暂缓到议税定案」，可点单格或确认本田的私田批量暂缓。田格标出「暂缓」并保留原种法。暂缓预览可查看今夜安排，返回后仍在原井田。延期研究期间可用「现在恢复续播」提前接续。选择传统或改革时，召简提示将恢复的格数。

常规会期前，筹备账显示第二年的时令交货进度和最早请议日期。点「查看时令单」可去备货。完成两季且已到请议日期时，提前请议栏列出还缺的爵位或纳贡。条件齐备后手记提示「请议已就绪」。在筹备账主动递交回执后，召简来堂前候议。交「岁末麦帛」前，交货簿会提示丝绸余量和议税所需。

达标后，封地手记和舆图人物页可标出召简。走到堂前按 E 打开议税面板，查看现有井田及四项库藏。改革、传统和暂缓并排显示，田赋下方先列结局门槛或研究经费。收成预估按当前成熟田格计算，包含轮作、门客增产、税后铜钱和桑叶。下方可对照周礼、忠诚及每夜用粮。正文跟随阅读字号，各案可同步滚动，方案名、离席和定案按钮留在画面内。滚轮或 Page Up / Page Down 可翻阅，Tab 在面板内循环。「离席」返回堂前，再见召简时按最新账目重算。

手柄十字键左右切换方案，按 A 预选。按下进入对照栏后可继续上下滚动，按右到可用的定案按钮。Esc 或 B 先清除预选，再按一次可离席。页脚随当前输入设备显示这一步的操作。点「定案」后执行选择、保存并恢复经营。暂缓一栏列出首笔扣款日、缺口及全部研究经费。研究期满或到期经费不足时，召简会说明缘由，只提供改革和传统。

定案后，可从手记的「结局目标」或实地账案查看贡簿或新税册，舆图标出所在。簿上逐项列出实绩、门槛及还缺的份数、匹数、铜钱或次数。首笔收成单列日期、经手者与实收。长些的正文随阅读字号放大并可滚动，簿名和页尾的呈交地点保持可见。目标行列出适用的成熟田格和可收份数，可逐格指路。传统路线只标成熟公田。改革路线同时预估收成的税后铜钱。

改革的铜钱目标仍有缺额时，市场可报价出售够用的余粮，列明取用品种和售后余额。报价先留出今夜尚缺的门客口粮、时令单用料和已经留用的节庆用料。若余粮只够补一部分，按实际可售数量报价。确认后扣作物、入铜钱，仍可用原市场选项自行卖粮或备粮。

全部路线目标达成后，封地手记可标出呈交账簿的位置。传统线在堂前呈交贡簿，改革线在南路亭呈交新税册。靠近账簿按互动键后，先看召简接册。留任的熟人可在案边说一句本局的话，然后镜头回到井田。结算记录邻里对白和近期的交货、节令与邻里活动。续营后可在原地查阅通关记录。

结算使用朱漆簿封和铜边栏。簿首页显示封地名、结局和存档记下的通关日期。路线结算注明「实绩 / 门槛」，旧格式的库存和铜钱列为「封地账目」。新结算会记下定案后的首笔收成、最多三件近期记事，以及通关时的井田、留任门客、灌溉和蚕室情况。最大字号下，账目与记事各占一行宽，先读账目，再读记事与辞别。正文可滚动，封地名和底部操作保持可见。首次打开结算时选中「继续经营」。开启自动存档时，呈交账册后会保存结局。

十字键可切换结算页脚的操作，也可选中滚动条阅读长记事。正反向 Tab 均在当前页或读档确认框内循环。从簿中重看结尾，播完或跳过都会回到原来的阅读位置及「重看结尾」按钮。「读取通关前存档」会显示档位和日期，取消后接着读原处。跳过结尾、取消读档和离开回看账簿的按钮随当前输入设备显示 Esc 或 B。

战败与失地结算写明封地名、发生日期与失败原因，下方列本局已到过的最近可恢复档位和时辰。读档遇到存档变更时，结算显示新档位，等玩家再次选择。结算文字随阅读字号调整。有可读进度时聚焦「读取最近存档」，否则聚焦「返回标题」。方向键、十字键和 Tab 在结算内切换操作，Esc 或 B 返回标题。

从系统设置或尚未保存的结算返回标题时，确认框列出当前封地、日期和最近的存档，默认选中「保存并返回」。关窗确认用同样的布局，正文和操作都跟随阅读字号。方向键和手柄十字键可切换操作，取消后回到原来的焦点。保存失败会留在确认框并提示重试。选「直接返回」或「直接退出」会放弃尚未保存的进度。

标题的主按钮和存档列表按记录的当前状态区分「查看结算」「继续经营」和「查看战败结算」。存档列表先写打开后的入口和路线，再列档位与日期。已保存的结算也会提示可从「选择存档」重看。

标题按钮、新建封地的名称栏和表单文字随阅读字号变化。手柄十字键可切换标题选项，打开新建封地时先选中「开始新游戏」。用键盘打开时选中建议的封地名，便于直接替换。留空使用默认名。Esc 或 B 返回「新建游戏」，从设置返回时回到「设置」。若地图读取失败，再次打开新建封地时保留已填的名称。

选档页左栏随上下方向键切换封地，右栏立即显示该封地的完整名称与存档。右方向键或 Tab 进入记录，左方向键回到所选封地。Tab 按记录、返回按钮、所选封地的顺序循环。手柄十字键沿用方向键的移动顺序，摇杆仍能移动光标。无法读取的记录仍列在对应封地，焦点会跳过这些条目。标题上的最近存档摘要和选档页跟随阅读字号。长封地名与记录换行显示，两栏各自滚动，读取反馈和返回按钮留在页脚。页脚随当前输入设备提示操作。

替换每个手动档和自动档时，保留该档位上一份可用记录。主档不可用时，标题和选档页显示该档位可读取的备份。恢复经营档后，地图上会提示恢复的日期。三个自动档仍按保存顺序轮换。

「继续游戏」、选档页和结算恢复都以玩家看到的那份记录为准。若它已轮换到同档位的备份，可直接从备份读取。若主档与备份里都找不到这份记录，界面会更新可选记录，等玩家再次确认封地和日期。

若主档或备份由更新版本写入，该档位受保护。标题和选档页说明需更新游戏。同一档位还有可读记录时，可按显示的日期打开。手动保存遇到受保护档位会提示原因，自动存档跳过这些档位。更新游戏后可重新检查原记录。

在两个窗口打开同一封地时，如果另一处已保存了这次读档时尚未看到的记录，当前窗口会暂停该封地的自动保存。手动保存可改为「另存为封地副本」，结局可另存为带结局的副本。副本从当前时辰、位置和经营状态继续，并有自己独立的手动档及自动档。返回标题或退出前也能另存副本。

存档提示排在「今夜安排」上方，跟随阅读字号换行。面板打开时暂时收起，返回地图后继续保留阅读时间。保存失败的提示会保留到新的存档反馈。自动保存遇到档位冲突时，设置页会直接提供「另存为封地副本」。

### 2.5 地图面板

#### 区域舆图

封地、西市和竹涧按 M 或手柄 Y 打开本地舆图，再选「区域舆图」。在溪桥道直接打开区域图。两张图切换时保持暂停，焦点落在对应的切换按钮。Tab、方向键和手柄十字键在当前显示的舆图中移动，按舆图键、Esc 或手柄 B 回到当前地点。通过按钮打开舆图或历书时，关闭后可接着操作原来的入口。切换本地舆图与区域舆图时也记住该入口。

图上从西向东画出西市、溪桥道、封地和竹涧。页首写明当前位置，图上用白心图钉标出起点。溪桥道的指路从桥面或草径上的当前位置画起。选地标或右侧区域按钮后，可继续选择摊位、钓点等去处，地点说明显示在名单下方。当前指路用金色实线，预览用青色虚线和菱形终点，两者同时显示，重合时仍可看见虚线两侧的金边。底栏用同样的线型对应两条路线。图上的地名、沿途关口和地点说明随阅读字号放大，确认后替换当前指路。跨图、存档续玩和取消指路沿用各地图的处理。

溪桥道、西市和竹涧在右上地名下显示当前指路。路签分开列出目的地、本段走法和「取消指路」，文字随阅读字号放大。西市先标出东口，溪桥道区分往西市东口与往封地西关，竹涧按所选路线提示西门或南路小径。打开舆图或设置时收起路签，回到地图后继续显示所选路线。

过关后的铜边地名牌写明到达的关口和前方地标。溪桥道两端分别说明往西过桥到西市、往东过桥回封地。进入西市、封地和竹涧时，牌上显示对应的路口、小径或地标。地名和提示随阅读字号调整，牌的位置会给顶部工具栏、晨间简报和临时消息留出空隙。淡入一结束就可继续操作，地名牌短暂保留。打开面板时收起。

右上地名、日期、时辰和竹涧的当日出行状态也随阅读字号放大。西市的铜钱和粮食各带图标，空间不足时各自成行，数字与单位留在一起。

竹涧、溪桥道和西市的顶部有「回井田」。区域舆图的「封地」也可选「井田 1」。指路沿道路过关，再走到第一块井田的南侧田口。出门前已有田务指路时，两处入口显示「接着田务」。返程指向当前该做的那块井田，并在田口接回具体地块、公私田范围和续播设置。若门客已经完成原地块的工作，优先标出同一井田的下一格符合条件的田。暂时没有合适的地块时，在田口结束指路。竹涧的南路小径已开通且走这边更近时，走南路并在舆图写明。途中手动保存会记录返程和先前的田务。

### 5.3 加载界面

封地、溪桥道、西市和竹涧之间在遮幕全闭后换场。成功到达时，上方居中的暗铜地名牌随揭幕浮现，并按阅读字号显示。揭幕结束即可继续操作，互动提示避开地名牌，地名牌随后淡出。抵达时弹出的议事界面，以及随后打开的舆图、设置和管理面板，会优先占用画面。

从标题新建、继续或从选档页读档时，缺少所需资源会先显示「正在打开封地」或「正在读取存档」。青铜加载牌按当前地图的实际读取项数推进，预备相邻关口时改为显示关口地图名与该阶段的项数。文字随阅读字号调整。读入结束后显示目的地，已备好的地图可直接进入。地图无法读取时提示原因并恢复菜单，可从「选择存档」挑选其他记录。

Windows 发行包加载封地时，两份读入较慢的场景脚本逐个在后台读取。等待期间加载牌继续绘制，收到读取结果后再更新完成数。若在标题的新建、继续或选档加载期间关闭窗口，加载牌改为「正在退出」，等正在读取的一项结束后取消本次进入并关闭游戏。

经过关口时，已备好的目的地直接揭幕。目的地尚未读入时，遮罩合拢后显示「正在前往」和地名，分批读完本次所需资源再揭幕。

## 6. 可访问性

### 6.1 颜色与形状

色觉辅助的设计覆盖关键交互提示，用图形和文字配合颜色传达状态。

田边、井田舆图和过夜的公田小图共用三种形状。实方表示可收，空菱表示待浇，叉号表示断水。舆图另以圆点标待播，田务按钮把符号、名称和格数并排显示。

挖渠、填渠和装闸的预览用加号标将接水的位置，用减号标将失水的位置。渠线碰到井田或屋基时，叉号标出阻挡格，提示文字写明原因。

### 6.2 字体大小

标题和游戏内的「系统设置」共用「阅读字号」。标准、较大和最大三档的对白正文分别为 18、21 和 24 个逻辑像素。封地手记、邻里手记、历书、交货簿、结尾字幕和结算正文随档位放大。所选字号立即应用并在重启后恢复。

长对白可在正文区用滚轮、PgUp 和 PgDn 或手柄 LB 和 RB 翻页。选项始终留在正文下方，翻页时保持当前选项的焦点。

### 6.3 快捷键自定义

- 「系统设置 → 键盘键位」可修改四向移动、互动、舆图、历书、路餐、敲钟与收线、七个选种槽、填渠和放样换弯。按单键设置。双方都可使用对方的键时可以互换，Esc 取消捕获，可恢复默认。
- 键位随系统设置保存并在所有封地生效。方向键、回车、Tab 和 Esc 保留为通用菜单键。方向键仍可移动主角。
- Windows 手柄按 Xbox 布局标注。左摇杆或十字键走路，右摇杆移动准星，A 操作田格、拖过同一块井田或点击面板按钮。标题、交接简、舆图、历书、封地管理和今夜安排可用十字键选中操作，用任一摇杆移动准星。
- X 互动或进行节奏操作，B 返回，Y 舆图，View 历书，LB/RB 循环换种。按下左摇杆缩小，按下右摇杆放大。RT 射箭，LT+A 填渠，Menu 在放样时换弯。
- 封地手记和耕作提示随最近使用的输入设备切换。设置面板列出常用手柄操作。
