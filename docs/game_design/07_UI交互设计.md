# 《采邑春秋》UI交互设计

## 设计原则

1. **信息层级**：重要信息优先显示
2. **操作便捷**：常用功能一键到达
3. **视觉统一**：青铜器风格贯穿全游戏
4. **响应及时**：操作立即反馈
5. **符合史实**：春秋时期审美

---

## 1. HUD设计

当前 Windows 版本的封地界面以实机布局为准：左上手记只提示下一步，右上集中日期、节气、爵位和物资，气血与体力收在左下。底部七个作物槽可以点选或按 1–7，选中种子与地图上的播种提示同步。鼠标指向田格时会先显示公私归属、操作及耗费；缺水或体力不足会说明原因，湿土和收获提示用于确认结果。

新建封地时，进场短提示交代渠伯留下了交接简。首次纳贡前，可从手记读简，查看中央公田和四周私田的用途，也可立即给渠伯指路。读取旧进度时，可继续读简，交接提示只随新建封地出现。

第一次纳贡前，手记根据田格实际操作标出公田、黍种或睡觉按钮。公田超出视野或被界面挡住时，屏幕边缘会指向它。公田有水、还在生长时，可以从手记给当日来客或渠伯指路。第一天和渠伯交谈时，他会说明公田纳贡、私田换粮的用途。首次公田收成入库后，地图标出手记所说的私田，玩家可自行点「找渠伯谈轮作」切换指路。邻里手记的「在地图上找」也能指向人物现在的位置，交谈或人物离场后清除标记，可从封地手记取消。

顶部「舆图」和 M 打开封地舆图并暂停活动。地点、井田、人物和竹涧四页可选指引目标，M 或 Esc 回到封地。工地完工和人物到访状态在下一次打开时更新。「竹涧」显示当日可采或可钓的东西和东岸风险，选定地点后指引从封地东关接到竹涧山路。

首次纳贡后，可以循标记找渠伯谈轮作。尚未收过私田时，手记会标出私田，优先指向已种、较早可收的作物。答应轮作后，翻好空田会标出菽种。私田收成入仓后，可以从手记打开市场，查看一份作物的转粮报价。

收过私田后，封地手记显示中士的声望门槛和招募花费。过夜晋升时显示新爵位和井田上限。「开垦」面板列出当前田额、门客与粮钱，提供找来客、打开市场和选地后的立桩入口。

管理面板的市场显示粮仓、私田库存、铜钱和当前门客每夜的粮耗。三种交易共用数量框，点击前显示该笔收支。三夜口粮按当前粮耗补足缺口，优先用私田作物，余量购粮。任一资源不足时，整笔备粮不扣库存。

管理市场的「指路去粮摊」先指向西路，进西市后继续指到粮摊。M 或手柄 Y 打开西市舆图并暂停活动，可点选摊位、收货牌和回封地的关口。粮摊复用市场交易表，鱼摊打开溪鱼簿，绸摊显示丝绸库存与每匹售价。靠近摊前按 E，按 Esc 回街上，交易和设置面板打开时时辰暂停。

时令单缺鱼时会显示当天的钓点或鱼的栖息提示。学会垂钓后，可从封地的时令单直接为当天能钓到的所需鱼种指路。体力不足或当天已有外出收获时，交货簿会显示原因。

「睡觉」上方的「今夜安排」显示缺水或口粮信息。打开后可以看已有多少作物可收、明早公私田各有几格新熟，以及停长的原因。「找待浇田」优先指向公田，同类田格中选离玩家最近的一格，供水后清除标记。

同一面板可设置夜间备粮和购粮上限，预览用粮、留货和费用。换季时按次日时令单留货。管理市场也能打开此面板。过夜画面显示新增成熟格数，最近一夜的田务与实际用粮随晨间存档保留，可在面板重读。

六艺页显示书的当前等级和经验。每天可研读一次，次数随存档保留，过夜后恢复。书达到 2 级可建蚕室，达到 3 级可在科技页解锁水利。

### 2.4 事件面板

达标后，封地手记和舆图人物页可标出召简。走到堂前按 E 打开议税面板，查看现有井田及四项库藏。改革、传统和暂缓并排显示。收成预估按当前成熟田格计算，包含轮作、门客增产、税后铜钱和桑叶。两条路线同时列出结局门槛、周礼、忠诚及预计每夜用粮。「离席」返回堂前，再见召简时按最新账目重算。

点方案只高亮当前选择，按 Esc 可清除。点「定案」后执行选择、保存并恢复经营。暂缓一栏列出首笔扣款日、缺口及全部研究经费。研究期满或到期经费不足时，召简会说明缘由，只提供改革和传统。

## 5. 反馈设计

### 5.1 浮动文字

**获得资源**：
```
+5 金钱 (金色上浮)
```

**消耗资源**：
```
-10 粮食 (红色下浮)
```

**经验获得**：
```
+15 XP (紫色上浮)
```

### 5.2 通知系统

#### 通知类型

| 类型 | 图标 | 颜色 | 持续时间 |
|------|------|------|----------|
| 信息 | ℹ️ | 白色 | 3秒 |
| 成功 | ✓ | 绿色 | 3秒 |
| 警告 | ⚠️ | 黄色 | 5秒 |
| 错误 | ✗ | 红色 | 5秒 |
| 解锁 | 🔓 | 紫色 | 5秒 |

#### 通知队列

- 最多同时显示3个
- 新通知从右侧滑入
- 旧通知向上移动或淡出

## 6. 可访问性

### 6.1 色盲模式

- 正常模式：红/绿/蓝
- 色盲模式：使用图标+文字，避免仅用颜色区分

### 6.2 字体大小

- 小：12px
- 中：14px（默认）
- 大：18px

### 6.3 快捷键自定义

- 「系统设置 → 键盘键位」可修改四向移动、互动、舆图、历书、路餐、敲钟与收线、七个选种槽、填渠和放样换弯。按单键设置。双方都可使用对方的键时可以互换，Esc 取消捕获，可恢复默认。
- 键位随系统设置保存并在所有封地生效。方向键、回车、Tab 和 Esc 保留为通用菜单键。方向键仍可移动主角。
- Windows 手柄按 Xbox 布局标注。左摇杆或十字键走路，右摇杆移动准星，A 操作田格、拖过同一块井田或点击面板按钮。标题与模态面板可用任一摇杆或十字键移动准星。
- X 互动或进行节奏操作，B 返回，Y 舆图，View 历书，LB/RB 循环换种。按下左摇杆缩小，按下右摇杆放大。RT 射箭，LT+A 填渠，Menu 在放样时换弯。
- 封地手记和耕作提示随最近使用的输入设备切换。设置面板列出常用手柄操作。
