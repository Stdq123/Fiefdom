# 《采邑春秋》UI交互设计

## 设计原则

1. **信息层级**：重要信息优先显示
2. **操作便捷**：常用功能一键到达
3. **视觉统一**：青铜器风格贯穿全游戏
4. **响应及时**：操作立即反馈
5. **符合史实**：春秋时期审美

---

## 1. HUD设计

当前 Windows 版本的封地界面以实机布局为准：左上手记只提示下一步，右上集中日期、节气、爵位和物资，气血与体力收在左下。底部七个作物槽可以点选或按 1–7，选中种子与地图上的播种提示同步。鼠标指向田格时会先显示公私归属、操作及耗费；缺水或体力不足会说明原因，湿土和收获提示用于确认结果。

将鼠标或手柄光标停在种子上可查看作物卡。成熟贴图下衬该作物的古字，旁边列出繁体字头、可查证的字形年代、种植用途和今日播种所需夜数。

新建封地时，进场短提示交代渠伯留下了交接简。首次纳贡前，可从手记读简，查看中央公田和四周私田的用途，也可立即给渠伯指路。读取旧进度时，可继续读简，交接提示只随新建封地出现。

第一次纳贡前，手记根据田格实际操作标出公田、黍种或睡觉按钮。公田超出视野或被界面挡住时，屏幕边缘会指向它。公田有水、还在生长时，可以从手记给当日来客或渠伯指路。第一天和渠伯交谈时，他会说明公田纳贡、私田换粮的用途。首次公田收成入库后，地图标出手记所说的私田，玩家可自行点「找渠伯谈轮作」切换指路。邻里手记的「在地图上找」也能指向人物现在的位置，交谈或人物离场后清除标记，可从封地手记取消。

对话卡在底部同屏显示说话者的肖像、身份、对白和可选回应。长对白会撑开卡片，选项空间不足时可换行。只有一个可用选项时，按当前互动键或手柄 X 继续。多个选项时，方向键或手柄十字键在可用选项间切换，回车或 A 确认。打开时焦点落在结束对话的选项上，Esc 或 B 可直接返回。

田格的悬停提示和田务指路共用封地界面的遮挡范围。靠近手记、历书或种子栏时，田格提示移到田格旁有空位的一侧。井田指路仍标出下一格可收、待浇或断水的作物。

在田边水源按互动键或手柄 X，可查看渠水用途和书艺门槛。书艺未到 3 级时可直接打开六艺研读，达标后可进入科技解锁水利。解锁后可查看接水的井田数和田格数。当第一块井田还无渠水且有可直达的渠线时，会列出尚需开挖的格数、铜钱和缺额。选「标出引水位置」进入挖渠，沿金框逐格施工。接通后金框消失。

本季或下季夏单的备稻量超过私仓、已熟稻和接水私田可提供的数量时，交货簿可跟踪该单并指路去水源。西市先指向东口，经溪桥道回封地后接到泉边。路线与订单进度都可随存档恢复。已有水利时，泉边按现有渠线为首块井田报价，优先给所缺的稻留出足够私田。选「标出备稻渠线」后金框标渠，青框标田。玩家逐格开挖，退出挖渠时自动选中稻种。

顶部「舆图」和 M 打开封地舆图并暂停活动。地点、井田、人物和竹涧四页可选指引目标，M 或 Esc 回到封地。工地完工和人物到访状态在下一次打开时更新。「竹涧」显示当日可采或可钓的东西和东岸风险，选定地点后指引从封地东关接到竹涧山路。

舆图地点页和六艺页均可指路到驾御场。在屋内选中时提示从南门回封地，地上的金线沿东关前的岔路到坡下马车。上车后底部种子栏换成驾御进度和下车按钮。开始移动后倒计时启动，当前旗门和停车线依次亮起。完成后显示用时和所得御经验，六艺页保留最快用时。

首次纳贡后，可以循标记找渠伯谈轮作。尚未收过私田时，手记会标出私田，优先指向已种、较早可收的作物。答应轮作后，翻好空田会标出菽种。首年任下士时，私田收成入仓后可从手记查看今夜粮耗、时令交货期限、备货进度和报酬。转粮按钮写明取用哪种作物，交货会用到的作物也会标明。可换一份口粮，或留作物并打开时令单。作出选择后收起这条指引，存档保留选择状态。

封地手记在首次纳贡后显示下次期限，首贡将到期时也会提醒。点期限打开「今夜安排」，可以看累计奖励进度、当晚欠贡的声望损失和最早可收的公田。空地可选短周期旱作并标出播种格，已播种时可循标记浇水、接渠或收割。成熟日期按后续每夜供水估计。公田入库后期限重新计算，发生的扣分可在「昨夜结算」重看。

收过私田后，封地手记显示中士的声望门槛和招募花费。过夜晋升时显示新爵位和井田上限。「开垦」面板列出当前田额、门客与粮钱，提供找来客、打开市场和选地后的立桩入口。

管理面板的市场显示粮仓、私田库存、铜钱和当前门客每夜的粮耗。三种交易共用数量框，点击前显示该笔收支。三夜口粮按当前粮耗补足缺口，优先用私田作物，余量购粮。任一资源不足时，整笔备粮不扣库存。

管理市场的「指路去粮摊」先指向西路，进西市后继续指到粮摊。M 或手柄 Y 打开西市舆图并暂停活动，可点选摊位、收货牌和回封地的关口。粮摊复用市场交易表，鱼摊打开溪鱼簿，绸摊显示丝绸库存与每匹售价。靠近摊前按 E，按 Esc 回街上，交易和设置面板打开时时辰暂停。

走近摊前会看到摊主姓名。打开柜台后，肖像与摊主的话放在交易账的左侧。渔生会说明去哪里学钓鱼、怎样交留鱼单，以及本季留鱼是否已经收到。绸摊切换到羊毛交易时继续由蔡娘接待。

时令单缺鱼时会显示当天的钓点或鱼的栖息提示。学会垂钓后，可从封地或西市的时令单、西市鱼摊给当天能钓到的鱼种指路。西市出发先标东口，经封地东关进入竹涧后接到钓点。体力不足或当天的垂钓机会已用完时，交货簿会显示原因。

钓鱼结果和竹涧舆图可为当前能交的留鱼单或带鱼的时令单指路。两单均备齐时，鱼摊和收货牌分别可选。返程沿竹涧西门到封地，再走西关至所选去处。取消指路会清除整段目的地，在三张地图上存档都可接着走。

竹涧右上角的「设置」、Esc 或手柄 B 可在山路上打开系统设置并暂停活动。南路小径开放且沿山路更近时，保存会提示从南路小径继续。其余情况提示从西门继续。标题与存档列表显示「竹涧」，从设置内读档默认先看当前封地的记录。

「睡觉」上方的「今夜安排」显示缺水或口粮信息。打开后可以看已有多少作物可收、明早公私田各有几格新熟，以及停长的原因。「找待浇田」优先指向公田，同类田格中选离玩家最近的一格，供水后清除标记。

蚕桑页把单件缫丝、织绸与可用的批量操作并排。两项夜间安排分别控制续养和门客缫丝。蚕桑页和「今夜安排」共用喂叶、结茧与缫丝预报，过夜后可重读实际结果。

同一面板可设置夜间备粮、购粮上限和缺粮时按整份补粮，预览用粮、留货与费用。换季时按次日时令单留货。次日应缴的研究费显示预留金额或备粮后的缺额。缺粮时可选择先供哪位门客，预览足份、缺餐和离任名单，也可打开市场备粮或调整门客分工。

过夜画面显示新一天、节气和一条简短提示。结算结束后，日历下的「昨夜结算」会提示缺粮、爵位变化、井田完工或新熟格数，可直接打开田务、用粮和蚕棚实绩，查看研究缴费。仍有熟田时，可点「找可收田」，收下当前格后指引接到下一格。昨夜记录可切换到「今夜安排」，并随晨间档和手动档保存。旧档已有的田务和用粮记录可在同一处查看。

邻里手记在人物原有故事下记离任与返岗。返访时可在手记指路，交谈后选「请回来」。缺餐离任的对话和手记列出粮仓现有口粮与返岗后的总粮耗。粮仓备足且满足招募条件时，「请回来」可以确认。

六艺页显示书的当前等级和经验。每天可研读一次，次数随存档保留，过夜后恢复。书达到 2 级可建蚕室，达到 3 级可在科技页解锁水利。

### 2.2 门客管理面板

Windows 版从顶部直接选择封地概览、市场、君子六艺、科技、蚕桑、溪行手记、时令单、邻里手记和溪鱼簿。栏目一行显示，当前页有金色选中状态。键盘可用左右方向键选栏目并按回车打开，Tab 可移到栏目和页内控件，Esc 返回。手柄 LB/RB 可循环换页，B 返回。打开职责下拉菜单或今夜安排时，当前栏目保持原样。平时在封地用 LB/RB 换种。

门客名单在左侧，可分派职责，或把人物拖到封地概览的井田格指定优先田。邻里手记和溪鱼簿用整页宽度显示。首次打开时聚焦当前栏目，关闭后可接着操作打开管理的按钮。

第二块井田完工后，职责菜单可选「井田管事」。管事卡片上可选择一块完工井田，拖到田格也会切换负责的井田。封地概览显示该田的管事，续播仍在田格或批量安排中设置。岗位提示显示每夜所需口粮。

### 2.4 事件面板

第二块井田完工或晋升上士后，封地手记可打开议税筹备账。日期和爵位单列，公田占比旁写明累计纳贡、私田收成和缺额。成熟田地的收成预估列出两种收获顺序。六艺条件未满足时可打开六艺页。公田指路会接续到下一格成熟公田，并随手动存档保留。没有成熟公田时可打开井田舆图。

常规会期前，筹备账显示第二年的时令交货进度和最早请议日期。点「查看时令单」可去备货。完成两季且爵位、纳贡和日期达标后，手记提示「请议已就绪」。在筹备账主动递交回执后，召简来堂前候议。交「岁末麦帛」前，交货簿会提示丝绸余量和议税所需。

达标后，封地手记和舆图人物页可标出召简。走到堂前按 E 打开议税面板，查看现有井田及四项库藏。改革、传统和暂缓并排显示。收成预估按当前成熟田格计算，包含轮作、门客增产、税后铜钱和桑叶。两条路线同时列出结局门槛、周礼、忠诚及预计每夜用粮。「离席」返回堂前，再见召简时按最新账目重算。

点方案只高亮当前选择，按 Esc 可清除。点「定案」后执行选择、保存并恢复经营。暂缓一栏列出首笔扣款日、缺口及全部研究经费。研究期满或到期经费不足时，召简会说明缘由，只提供改革和传统。

全部路线目标达成后，封地手记可标出呈交账簿的位置。传统线在堂前呈交贡簿，改革线在南路亭呈交新税册。靠近账簿按互动键后，先看召简接册，再看本局田地和结算。结算记录近期的交货、节令与邻里活动。续营后可在原地查阅通关记录。

### 2.5 地图面板

#### 区域舆图

封地、西市和竹涧按 M 或手柄 Y 打开本地舆图，再选「区域舆图」。在溪桥道直接打开区域图。两张图切换时保持暂停，按舆图键、Esc 或手柄 B 回到当前地点。

图上从西向东画出西市、溪桥道、封地和竹涧。选地标或右侧区域按钮后，可选择该区域的摊位、钓点等去处。底部显示经过的地图与适用的关口，确认后才替换当前指路。跨图、存档续玩和取消指路沿用各地图的处理。

## 6. 可访问性

### 6.1 色盲模式

- 正常模式：红/绿/蓝
- 色盲模式：使用图标+文字，避免仅用颜色区分

### 6.2 字体大小

- 小：12px
- 中：14px（默认）
- 大：18px

### 6.3 快捷键自定义

- 「系统设置 → 键盘键位」可修改四向移动、互动、舆图、历书、路餐、敲钟与收线、七个选种槽、填渠和放样换弯。按单键设置。双方都可使用对方的键时可以互换，Esc 取消捕获，可恢复默认。
- 键位随系统设置保存并在所有封地生效。方向键、回车、Tab 和 Esc 保留为通用菜单键。方向键仍可移动主角。
- Windows 手柄按 Xbox 布局标注。左摇杆或十字键走路，右摇杆移动准星，A 操作田格、拖过同一块井田或点击面板按钮。标题与模态面板可用任一摇杆或十字键移动准星。
- X 互动或进行节奏操作，B 返回，Y 舆图，View 历书，LB/RB 循环换种。按下左摇杆缩小，按下右摇杆放大。RT 射箭，LT+A 填渠，Menu 在放样时换弯。
- 封地手记和耕作提示随最近使用的输入设备切换。设置面板列出常用手柄操作。
