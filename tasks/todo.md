# 《采邑春秋》Windows 1.0 执行清单

## A · 井田经营

- [x] **A1 水渠数据和存档**。已解锁水利后可在有效空地修渠，扣除配置成本，旧档默认无渠。验证连通、断开、重复建造和存读档。
- [x] **A2 稻田灌溉和反馈**（依赖 A1）。玩家从科技进入建渠模式。连接水源的渠供水，邻田显示湿润并按日生长，旱地播稻给出提示。验证手浇和旧档中已有的稻。
- [x] **A3 季节与轮作**（依赖 A2）。节气和作物信息在地图可读。至少一项季节变化影响经营，轮作的收益可由种植和收获对照验证。
- [x] **A4 桑叶生产**（依赖 A2）。收桑得到可辨认的桑叶，用作养蚕投入。验证公私田结算、库存和养蚕用量。
- [x] **A5 从养蚕到丝绸**（依赖 A4）。玩家完成喂蚕、结茧、织造和变现或送礼，过夜与读档保留进度。验证缺料、阶段完成和丝绸用途。
- [x] **A 验收**。新档完成一轮公私田、灌溉水稻及桑蚕链，修改生产配置后回归对应结果。

Godot 4.7.2 的 `irrigation-state`、`irrigation-flow`、`season-rotation` 和 `silk-chain` 四个隔离场景通过。水利路径通过本机 Vulkan 窗口验证。配置回归使用了 6 铜钱的渠价、每夜 5 桑叶的喂养量和 43 铜钱的丝绸售价。

## B · 开局与发展

- [x] **B1 标题与存档入口**。可新建和继续，空档或坏档有反馈。重新开始有清楚的档位影响，验证新旧进度及退出重进。
- [x] **B2 井田教程**（依赖 A2、B1）。在游戏中引导首轮耕作和纳贡，逐步提示招募和开垦条件。验证无说明书也可完成步骤，旧进度从对应阶段继续。
- [x] **B3 具名人物**（依赖 B2）。为入门与中段至少三种职责提供可辨认角色、头像和对话，访客行为与故事目标对应。验证首次会面、重复对话及招募后的身份。
- [x] **B4 门客分工**（依赖 A5、B3）。至少有两种会改变收益或风险的学派工作，玩家可指派并观察行为、粮耗与离开后果。验证同档分工与读档。
- [x] **B5 六艺正常成长**（依赖 B3）。六艺各有日常操作来源，至少可玩一次节奏练习和驾驭任务。验证每项经验、等级回显和重复收益规则。
- [x] **B6 晋升与封地**（依赖 B4、B5）。玩家能从界面看见升降爵条件，并靠正常经营和学习晋升。开垦成本和期限可理解，验证两次不同爵位的升迁及扩田。
- [x] **B 验收**。从标题新开档完成教学、至少一轮角色委托和两次晋升，并保存重进复核进度。

`title-flow` 验证了标题、引导和坏档处理。独立解压的测试构建在本机渲染了标题画面。`visitor-story`、`retainer-duties` 和 `six-arts` 通过。`estate-flow` 从新档第 23 天达到开垦条件，后续升到上士并读档。该场景隔离敌袭，攻防由 C 阶段验收。

## C · 攻防与结局

- [x] **C1 伤害与战败**（依赖 B1）。敌人能对玩家和封地造成可见损失，弓箭、避让和战败恢复可操作。验证攻击、被击中、战败后读档或重开。
- [x] **C2 野外与守田**（依赖 B4、C1）。野外有辨认得出的路径、资源和敌人。玩家可主动防御或分配门客守卫，验证带敌袭的经营循环。
- [x] **C3 初税亩战役衔接**（依赖 B6、C2）。从新档能在正常进度达到事件门槛。两个选择都给出后续目标，延期费用和最后期限可查。
- [x] **C4 两条结局**（依赖 C3）。传统和改革产生不同的终局条件、画面和统计，玩家可结算后回标题。验证达成、未达成、延期和读档回放。
- [x] **C 验收**。从正常入口跑通两个新档结局及战败恢复，记录完成天数、资源和关键事件。

`combat-recovery` 验证斥候箭伤、野狗咬伤、玩家射箭、战败读档、欠贡降爵和失地后重开。`raids-forage` 从新档正常招募，验证第 8 天预警、敌袭读档、军务门客防御及野外每日采集。

两条新档路线均在第 53 天、大夫爵位且公田占比约 30.5% 时触发初税亩。传统路线经延期经费不足后作出抉择，改革路线直接采纳新法。两个结局均验证了抉择后保存、从标题继续、达成结局、保存结局与重读结局。资金充足的延期场景另外验证了 24 天到期、累计扣款 1,200 铜钱，以及中途读档不会重复扣款。

## D · 观感与发布

- [x] **D1 封地和野外画面**（依赖 A2、C2）。田地、道路、建筑和进出标记在游戏分辨率下可辨，验证移动、遮挡、选址和空旷区域。
- [x] **D2 人物与操作反馈**（依赖 B3、C1）。关键人物有可区分的服饰、肖像和行为反馈。验证耕作、演奏、受伤、战败与结局画面。
- [x] **D3 界面与声音**（依赖 C4、D2）。标题、教程、管理和结算使用一致样式，可读按钮、操作反馈和声音在设置后继续生效。验证窗口缩放、键鼠、静音和设置重载。
- [x] **D4 发布构建**（依赖 D1、D3）。输出 Windows x64 1.0 ZIP 和操作说明，保留构建命令、授权与验收记录。验证独立解压启动、生产配置和本机实画面。
- [x] **D 验收**。最终发布版复核新档两条结局、失败恢复、旧档兼容和持续运行，再关闭目标。

- 正式程序验证了配乐和动作音效初始化以及主音量静音。源码的 `settings-flow` 验证音量与窗口偏好在保存后重新载入。
- 从 0.1.0 和 0.1.1 的独立解压程序生成存档。1.0 从标题载入，保留经济、爵位、粮仓、在田作物和门客身份。两个档均从第 3 天继续至第 4 天，旧作物生长一阶并成功再次存档。
