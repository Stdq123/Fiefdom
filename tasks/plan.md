# 《采邑春秋》Windows 1.0 交付计划

## 正式版范围

以 0.1.1 试玩版为基础，交付可独立运行的简体中文 Windows x64 正式版。玩家从标题界面开始，经过井田教学、开垦和门客经营，在野外取得资源并守住封地，最后经初税亩抉择走向传统或改革结局。战败和失地有明确结果，玩家可从标题重开或从存档继续。

正式版采用一段能完整体验的封地经营战役。玩法、美术和叙事按这段战役的需求落地，其他平台和总览中的扩展路线列为后续版本内容。每条故事一起完成规则、入口、状态反馈和存档，再统一画面和声音。详细验收项及依赖见 [执行清单](todo.md)。

## 完成顺序

1. **井田经营。** 接通水渠与稻田，完善轮作和季节反馈，打通桑叶到丝绸的经营链。
2. **开局与中段。** 提供标题、新建和继续，逐步引导第一次纳贡、招募与开垦。用具名人物串起门客分工、六艺练习和晋升条件。
3. **攻防与结局。** 加入可读的敌袭、伤害和战败处理。让传统、改革和延期有不同的经营代价、可达成目标与后续结算。
4. **画面与操控。** 完成封地、道路、水渠、屋舍和野外的可辨认画面。统一人物、关键界面、动作反馈和声音，核对键鼠和窗口模式。
5. **正式包与验收。** 兼容 0.1.x 存档，验证新档的两条结局路线、失败恢复与设置。导出 Windows x64 1.0 ZIP，在独立目录验证运行，附操作说明和引擎授权。

## 完成标准

- 正常菜单可以新建、继续、设置和退出。首次游玩能通过游戏内提示完成播种、纳贡、招募、开垦和选择结局。
- 至少两条可达结局在流程、条件和结算上有明显区别。验证时从新档开始，通过游戏内入口取得声望、资源和经验。
- 水利、桑蚕、学派分工、六艺和野外攻防都能让玩家做出选择，并能从画面或状态变化判断结果。
- 新旧档均可进入游戏。中途退出、作出初税亩决定、战败和通关后的存读档有确定的恢复行为。
- Windows 发布构建不含调试入口。至少在本机做独立解压启动和实画面验证，记录显卡、分辨率、长跑结果和支持边界。
