# 验收故事

1. 按用户请求、设计和故事验收条件审查相关文件。区分本次交付和工作区原有改动，核对代码变更是否覆盖正常入口及相关旧数据。
2. 为每条验收条件记录通过、失败或待验证及其证据。核对 Godot 冒烟输出。界面布局用实际截图或实机记录，手感用试玩记录，存档兼容用旧存档场景复现。
3. 仅当适用的验收项均通过时标记完成。有失败或证据缺口时，写出具体复现步骤或下一项检查。若已有故事文件，将结论写入它的验证证据部分。
